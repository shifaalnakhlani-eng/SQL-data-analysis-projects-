# Zepto SQL Data Analysis

SQL analysis project using the Zepto dataset.

## Files
- `Zepto_SQL_data_analysis.sql` — SQL analysis queries.
- `zepto_v2.csv` — source dataset.

## Run
Load `zepto_v2.csv` into your SQL database, then run the SQL script in your database client. Adjust table or schema names if your local import uses different names.
