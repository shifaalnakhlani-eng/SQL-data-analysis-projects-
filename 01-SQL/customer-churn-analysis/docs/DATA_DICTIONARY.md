# Data Dictionary
| Field | Meaning |
|---|---|
| customerID | Unique customer identifier |
| gender | Gender category in sample |
| SeniorCitizen | 1 = senior citizen; 0 = not senior citizen |
| Partner | Whether customer has a partner |
| Dependents | Whether customer has dependents |
| tenure | Months with company |
| InternetService | Internet service type |
| TechSupport | Whether technical support is subscribed |
| Contract | Contract type |
| PaperlessBilling | Whether paperless billing is enabled |
| PaymentMethod | Payment method category |
| MonthlyCharges | Current monthly charge |
| TotalCharges | Total charges recorded; raw column is text |
| Churn | Yes if customer left within the last month represented in sample |

Other service fields include PhoneService, MultipleLines, OnlineSecurity, OnlineBackup, DeviceProtection, StreamingTV and StreamingMovies.
