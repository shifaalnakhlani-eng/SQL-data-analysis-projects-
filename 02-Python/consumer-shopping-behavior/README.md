# Consumer Shopping Behavior Analysis

Exploratory analysis of consumer shopping survey responses.

## Tools
- Python
- pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Analysis covered
- Initial data inspection, missing-value checks and duplicate checks
- Age and timestamp type conversion and age-group segmentation
- Missing-response / survey drop-off exploration
- Shopping-mode preference cross-tabulation
- Satisfaction, review trust and purchase regret by age group
- Country and occupation comparisons, including BNPL usage
- Payment-method and spending-category pivot tables
- Charts for age distribution, satisfaction, payment mix and discount importance

## Dataset required
Place the original file at:

`data/consumer_shopping_behavior_survey.csv`

The notebook upload did not include the CSV, so the dataset is intentionally not fabricated or substituted. Add the source dataset before running the notebook.

## Run locally
1. Install dependencies: `pip install -r requirements.txt`
2. Open `notebooks/consumer_shopping_behavior_analysis.ipynb` in Jupyter.
3. Ensure the CSV is saved in the project's `data/` folder.
